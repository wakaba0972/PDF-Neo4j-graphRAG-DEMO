# 文件目錄

專案說明文件集中放在此資料夾。安裝、啟動與基本使用方式請見根目錄的 [README.md](../README.md)；開發規範（提交、測試、LLM prompt 語言）請見根目錄的 [AGENTS.md](../AGENTS.md)。

## 建議閱讀順序

新加入的組員或 agent 建議依序閱讀：

1. [../README.md](../README.md)：專案功能、安裝與啟動
2. [交接紀錄.md](交接紀錄.md)：目前狀態、頁面流程、近期改動與注意事項
3. [目錄說明.md](目錄說明.md)：各目錄與檔案的用途
4. [改善計畫.md](改善計畫.md)：各改善項目完成狀態與待修正問題

## 維護規則

- 新增說明文件時放在 `docs/`，並在上方清單補一列。
- 根目錄只保留 `README.md` 與 `AGENTS.md`；`AGENTS.md` 必須留在根目錄，agent 工具才會自動讀取。
- 移動或改名文件時，同步更新 [目錄說明.md](目錄說明.md) 與其他文件中的連結。
