# 題目集匯入與實驗結果格式範例

實驗頁接受 JSON 或 CSV 題目集。以下使用 JSON 示範目前建議的跨文件來源格式，以及「匯出實驗結果 JSON」產生的完整逐題結果與簡潔指標結果。

## 題目集匯入範例

JSON 可直接放入題目陣列，或使用 `questions` 包住題目陣列。每題的 `number`、`question`、`expected_answer` 為題號、題目及正確答案；`question_sources` 和 `answer_sources` 分別記錄題目與答案的來源文件及頁碼。來源可跨文件，每份文件可列出多個頁碼。

```json
{
  "questions": [
    {
      "number": 1,
      "question": "如何在無線網路設定中使用 WPS-PBC？",
      "expected_answer": "確認無線路由器支援 WPS，然後在印表機控制面板選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
      "question_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [42, 43]
        }
      ],
      "answer_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [43]
        },
        {
          "document_id": "",
          "document_name": "ALCX17_NetworkGuide_TC.pdf",
          "pages": [8, 9]
        }
      ]
    },
    {
      "number": 2,
      "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
      "expected_answer": "先停止列印並小心取出卡紙；若剛完成列印，定影器及其周圍部件可能很燙，應避免觸碰。",
      "question_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96]
        }
      ],
      "answer_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96, 97]
        }
      ]
    }
  ]
}
```

`document_name` 請填專案內的 PDF 檔名。`document_id` 可留空，匯入時系統會依專案文件資訊配對；若有可靠的文件 ID，也可一併填入。每筆來源物件的 `pages` 必須是非空正整數陣列；空陣列、0、負數及非整數頁碼會被拒絕。沒有已知題目來源時可令 `question_sources: []`；沒有 Gold 答案來源時可令 `answer_sources: []`，此題不納入檢索指標平均。不要用 `{ "document_name": "...", "pages": [] }` 表示無 Gold。

舊式欄位仍可匯入，但只適合單一來源文件：

```json
[
  {
    "number": 1,
    "question": "如何在無線網路設定中使用 WPS-PBC？",
    "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
    "question_source_pages": [42, 43],
    "answer_source_pages": [43],
    "document": "ALCX17_UsersGuide_TC.pdf"
  }
]
```

## 實驗結果匯出範例

完整逐題結果使用 `schema_version: 6`。匯出內容以可分析的評測數據為主，不放「已完成」等執行狀態文字。每個實驗組包含設定、摘要指標及逐題評測結果；最上層 `summary` 彙總所有實驗題次；人工修改過的判定會以 `manual_judgment: true` 標記。答案分數 `score` 為 0（錯誤）、1（部分正確）、2（全對）；`passed` 為相容欄位，僅在 `score` 等於 2 時為 `true`。實驗組參數以 `retrieval_config` 保存策略 ID、Top K、策略專屬參數、Reranker 與證據擴展設定。

```json
{
  "schema_version": 6,
  "project": {
    "project_id": "vehicle_a1b2c3d4",
    "name": "ALCX17"
  },
  "max_concurrent_requests": 5,
  "question_count": 2,
  "evaluation": {
    "judge_model": "gpt-4o-mini",
    "judge_reasoning_effort": "low"
  },
  "summary": {
    "question_count": 2,
    "correct_count": 1,
    "partial_count": 1,
    "correct_total": "1 / 2",
    "accuracy": 0.75,
    "evidence_hit_rate": 1.0,
    "evidence_recall_rate": 0.5,
    "evidence_precision": 0.75,
    "document_hit_rate": 1.0
  },
  "groups": [
    {
      "name": "混合檢索比較組",
      "parameters": {
        "answer_model": "gpt-4.1-mini",
        "retrieval_config": {
          "strategy_id": "hybrid",
          "top_k": 8,
          "params": {"candidate_top_k": 24, "effective_search_ratio": 3, "ranker": "naive"},
          "reranker": {"id": "llm", "params": {}},
          "expansion": {"id": "legacy_name_chunk", "params": {}}
        }
      },
      "summary": {
        "answer_model": "gpt-4.1-mini",
        "judge_model": "gpt-4o-mini",
        "question_count": 2,
        "correct_count": 1,
        "partial_count": 1,
        "correct_total": "1 / 2",
        "accuracy": 0.75,
        "evidence_hit_rate": 1.0,
    "evidence_recall_rate": 0.5,
        "evidence_precision": 0.75,
        "document_hit_rate": 1.0
      },
      "results": [
        {
          "number": 1,
          "question": "如何在無線網路設定中使用 WPS-PBC？",
          "document": "ALCX17_UsersGuide_TC.pdf、ALCX17_NetworkGuide_TC.pdf",
          "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
          "actual_answer": "在控制面板選擇 WPS-PBC，並在指定時間內按下路由器上的 WPS 按鈕。",
          "answer_model": "gpt-4.1-mini",
          "judge_model": "gpt-4o-mini",
          "score": 1,
          "passed": false,
          "reason": "步驟正確，但遺漏必要的操作時限。",
          "manual_judgment": false,
          "evidence_hit": true,
          "evidence_recall": 0.5,
          "evidence_precision": 0.5,
          "document_hit": true
        },
        {
          "number": 2,
          "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
          "document": "ALCX17_UsersGuide_TC.pdf",
          "expected_answer": "定影器及其周圍部件可能很燙，應避免觸碰。",
          "actual_answer": "定影器在列印後可能仍然很燙，請避免觸碰。",
          "answer_model": "gpt-4.1-mini",
          "judge_model": "gpt-4o-mini",
          "score": 2,
          "passed": true,
          "reason": "正確指出定影器高溫及避免觸碰。",
          "manual_judgment": false,
          "evidence_hit": true,
          "evidence_recall": 0.5,
          "evidence_precision": 1.0,
          "document_hit": true
        }
      ]
    }
  ]
}
```

最上層及每組 `summary` 都記錄 `correct_count`（全對題數）、`partial_count`、`question_count` 與易讀的 `correct_total`；最上層數字是所有組別的實驗題次加總。`accuracy` 是得分總和除以 `2 × question_count`，因此全錯為 0、部分正確為 0.5、全對為 1。檢索指標以 `answer_sources` 為 Gold Evidence，來源單位是文件 ID（無 ID 時使用文件名稱）與頁碼配對：`evidence_hit_rate` 是至少命中一個標註頁面的題目比例；`evidence_recall_rate` 是逐題命中的唯一 Gold 文件-頁面數除以該題 Gold 文件-頁面總數，再對有 Gold 頁碼的題目取算術平均；`evidence_precision` 先逐題計算命中的唯一文件-頁碼數除以取回的唯一文件-頁碼數，再對有 Gold 頁碼的題目取算術平均；`document_hit_rate` 是至少取回一份標註答案來源文件的題目比例。chunk ID 不參與比對，同一文件同一頁的多個 chunk 只算一筆。有 Gold 頁碼但沒有取回來源時 precision 為 0；無 Gold 或 Gold 沒有頁碼的題目不納入檢索指標平均。逐題欄位為 `evidence_hit`、`evidence_recall`、`evidence_precision`、`document_hit`。逐題 `score` 是最後採用的 0／1／2 分數；人工修改後會更新 `score`、將 `reason` 設為「人工評判」，並將 `manual_judgment` 設為 `true`。`passed` 僅為相容欄位，代表是否全對。每次匯出會同時產生唯一檔名 `experiment-results-<id>.json` 與 `experiment-summary-<id>.json`。

簡潔指標結果使用 `schema_version: 4`，只包含專案與評測設定、整體及各組的參數和摘要數據；不包含題目文字、標準答案、模型回答或逐題結果，適合快速彙整比較。

  },
  "groups": [
    {
      "name": "混合檢索比較組",
      "parameters": {
        "answer_model": "gpt-4.1-mini",
        "retrieval_config": {
          "strategy_id": "hybrid",
