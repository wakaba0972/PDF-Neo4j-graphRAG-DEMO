# RAGAS 評測指標

一般答案判定維持既有的 0／1／2 分與評判理由。於 1-5、1-6 或 2-2 的評測設定勾選「同時計算 RAGAS 指標」，才會額外呼叫 RAGAS；RAGAS 分數不會改寫答案判定，也不會改變得分正確率。

目前計算三項 0–1 指標：

- **Faithfulness**：回答中的陳述有多少能由檢索到的證據支持。
- **Context Precision**：檢索證據中，與問題及標準答案相關的內容排序表現。
- **Context Recall**：標準答案中的必要資訊有多少能在檢索證據中找到。

RAGAS 使用該頁選定的評測模型（預設 GPT-6 Luna），評分會增加模型 API 用量。逐題結果會保留三個分數與評測模型；摘要顯示各實驗組的平均值。匯出實驗結果時也會保留逐題 RAGAS 分數以及各組、整體平均值。

評分需要實際送給回答模型的檢索證據，因此系統在生成待評答案時會一併保存證據文字。若載入較早建立、沒有保存檢索證據的回答，RAGAS 會在該題回報無法計算；重新執行「檢索並生成回答」即可取得證據。
